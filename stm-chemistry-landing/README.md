# СТМ Формула - демо-лендинг

Статический прототип B2B-лендинга контрактного производства бытовой химии под СТМ.

## Что внутри

- `index.html` - структура страницы по ТЗ: первый экран, аудитории, продукты, сроки, документы, экономика, маркетплейсы, безопасность, кейсы, гарантии, пакеты и форма.
- `styles.css` - адаптивный визуальный слой без сборки.
- `script.js` - A/B-заголовок, валидация формы и события аналитики-заглушки.

## Демо

Открыть локально можно напрямую:

```text
prototype/stm-chemistry-landing/index.html
```

Для просмотра через локальный сервер:

```bash
python3 -m http.server 4173 --directory prototype/stm-chemistry-landing
```

Затем открыть `http://localhost:4173`.

## Интеграции

В `script.js` оставлен `YM_COUNTER_ID = null`. Для подключения Яндекс Метрики нужно заменить `null` на ID счетчика и добавить официальный код счетчика в `index.html`.

Форма сейчас работает в демо-режиме. В продакшене обработчик отправки можно заменить на CRM, Telegram-бота, email-шлюз или API сайта.
